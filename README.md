# Repositório para projetos da disciplina

## Atividade 1 AR

Utilizando os marcadores fiduciais Hiro ou Kanji, é possível colocar um vaso de planta para mostrar uma possível decoração para uma casa.

Para ver a demonstração, visite [este site](https://yamgomes.github.io/topicos-infra-3-ar-vr/atividade-1-ar/).

## Atividade 2 VR

Utilizando um visor de realidade virtual, podemos alongar o pescoço olhando para os diversos objetos em cena.

Para ver a demonstração, visite [este site](https://yamgomes.github.io/topicos-infra-3-ar-vr/atividade-2-vr/).
